# Easy Asset — Painel web (código-fonte)

Esta pasta contém o código do painel web (Vue 3 + Vite).

A documentação completa (tecnologias, funcionalidades, papéis, execução, usuários de teste, publicação e limitações) está no [README principal do repositório](../README.md).

Comandos rápidos, a partir desta pasta:

```bash
npm install
cp .env.example .env   # ajuste VITE_APP_API_URL
npm run dev            # desenvolvimento
npm run build          # gera dist/
```
